## 2. 生产约束及依赖顺序

1. 前端先确认完整 API URL 拼接，避免重复 `/api`；history 的任意合法前端路由需要 Nginx `try_files` 回退入口，同时 API 请求不得误返回 HTML。生产 axios 使用用户指定 HTTPS 域名。
2. Nginx 保留用户既有 SSL 与强制 HTTPS 管理方式，不额外叠加重定向导致循环。完整配置标明与宝塔现有站点配置合并或替换的边界；证书、站点 root 等未知真实路径采用常见默认值并明确列为部署时核对项，不冒充已验证服务器值。
3. 后端使用 `127.0.0.1:8080`；Nginx 转发方式须与后端 `/api` 路径相符。CORS 源为 `https://www.zhangbowen666.cn`，不得用全开放源掩盖配置错误。
4. MySQL 地址、库名、用户、口令及管理员初始化凭据通过环境变量/服务器受限配置提供。生产包不含真实凭据、H2 或开发数据配置，不提供可直接公开使用的默认管理员账号密码。Flyway 迁移保留历史顺序与中文说明，既有 V1/V2/V3 不为打包擅自改写。
5. 当前业务仍是每间 30 人，每个有效预约占 1 个名额、取消释放、同学生不得重叠；峰值占用与房间行锁事务重验必须保留。累计违规至少三次限制预约，管理员基于证据确认到场/迟到/爽约，不因生产配置新增无证据自动爽约。
6. 推进顺序为 T01/T02 并行实现及开发自测 → T03 最终装配 → T04 独立检查及可执行回归 → 原作者修复/测试复测 → T05 项目同步。不得将开发自测、独立测试、生产服务器上线和真人业务验收混记为同一结论。
