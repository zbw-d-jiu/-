# 前端生产打包说明

2026-10-15；前端开发角色 gpt-6.1-sol / medium。此文说明本轮实际生产构建配置，替代旧运行文档中的fetch、Hash路由与仅本地API入口说明；旧记录保留为历史。最终交付目录由主agent汇总为桌面“校园自习室预约系统打包”，本文作者仅负责frontend与本文，不操作公网或声称已部署成功。

## API与环境配置

原实现使用fetch，本轮按用户要求改为Axios全局实例，精确依赖版本1.20.0来自[官方npm registry latest](https://registry.npmjs.org/axios/latest)的本轮核验。保留Vue2.7.16与Element-UI2.15.14，未更换用户指定技术栈。实例定义在`frontend/src/api.js`：

```js
export const httpClient = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL || '/api',
  timeout: 20000
})
```

`request(path,options)`的业务调用保持兼容：例如`request('/orders',{method:'POST',body:{...}})`，body交由Axios转换JSON，Bearer从当前会话读取。非2xx与`success:false`优先呈现服务端message，保留错误status；401清空令牌并派发会话失效事件。网络/CORS失败和20秒超时给出可理解的中文错误，不假造HTTP状态。

生产`frontend/.env.production`只有公开网址：

```dotenv
VITE_API_BASE_URL=https://www.zhangbowen666.cn/api
```

开发缺省`/api`由Vite代理到本地8080；`frontend/.env.example`给出可公开的本地覆盖示例。所有`VITE_`变量会编入浏览器产物，不能放入数据库密码、令牌或其他秘密。构建时`VITE_API_BASE_URL`环境变量或`.env.production.local`可覆盖配置，正式打包前须检查实际产物地址。

## History路由与生产压缩

Vue Router采用`mode:'history'`、`base:import.meta.env.BASE_URL`，Vite `base:'/'`用于域名根目录部署。`/login`、`/rooms`、`/admin/dashboard`等页面直接刷新必须由Nginx回退`index.html`；`/api`仍单独反向代理后端，不能被页面回退规则吞掉。Nginx与最终目录结构由主agent提供。

Vite7.3.7采用esbuild压缩、`sourcemap:false`、`emptyOutDir:true`清理旧输出。`command==='build'`时`esbuild.drop=['console','debugger']`删除调试语句，开发服务保留console。构建控制台自身的进度与chunk提示不会被删除，这与浏览器产物内删除console是不同范围。HTTP gzip由Nginx静态响应配置实现，Vite显示的gzip估算体积不意味着已经生成或部署gzip响应。

```powershell
cd frontend
npm ci
npm run check
npm run build
```

使用Node20.19+或22.12+；本轮使用Node24.19.0与npm11.6.2。输出为`frontend/dist`，打包只复制dist静态产物，不复制node_modules、npm缓存、本机工具或账户配置。当前课程规模使用完整Element-UI，主chunk仍有大于500kB的提示；不将它误记为构建失败。

## 验证边界

语法与既有密码/时区纯函数检查为开发自检，构建成功及域名字符串存在不代表公网DNS、TLS、Nginx和真实后端已部署。生产Axios地址固定为指定HTTPS域名，不能用本地Vite代理来证明公网接口成功。最终端到端验证在目标服务器配置完成后执行，本轮不操作公网。依赖剩余Vue2/compiler告警见旧前端运行说明，升级Axios不意味着全部依赖零告警。

## 本轮实际执行结果

- 根会话确认停止前后端后运行`npm install`：exit0，增加27包，固定Axios1.20.0并同步唯一package-lock；审计仍提示既有4项（3低、1中），未强制修复或改变Vue2栈。
- `npm run check`：exit0，5个源码语法、三时区日期及UTF-8密码边界均通过。

- 对dist/assets全部JS用Babel AST遍历验证：指定生产API字符串存在，console成员节点0，DebuggerStatement节点0，源码映射文件0，JS文件1；仅读取本地产物，没有向公网发请求。

唯一改动范围：frontend请求封装、路由、Vite配置、依赖与锁文件、公开环境文件，以及本生产打包说明。主agent负责将dist复制到指定打包目录、Nginx配置和最终交付核验。
