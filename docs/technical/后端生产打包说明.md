# 后端生产打包说明

适用版本：Spring Boot 3.5.16 / JDK21 / MySQL8.0；生产访问来源为`https://www.zhangbowen666.cn`，HTTPS由宝塔Nginx终止。后端生产配置只监听`127.0.0.1:8080`，无需且不应直接对外开放后端端口。本文记录生产打包配置，不代表已连接或部署公开服务器。

## 普通生产构建与启动

在`backend`目录执行用户要求的普通命令，不需要`-Pprod`：

```bash
# clean清除过去演示构建的H2/config残留；-DskipTests编译测试但不执行测试。
mvn clean package -DskipTests

# 受控运行环境预先注入DB_PASSWORD，命令与输出不得打印数据库密码。
java -jar target/study-room-0.3.0.jar --spring.profiles.active=prod
```

生成的可执行jar包含Java生产类、MySQL驱动、Flyway和V1/V2/V3迁移、通用`application.yml`与`application-prod.yml`。默认H2依赖仅为test scope，测试配置位于`src/test/resources/application-test.yml`，演示配置保留在源码但普通构建明确排除，因此正式jar不包含H2、application-demo.yml或application-test.yml。

启动必须显式指定`prod`，否则会使用默认开发配置。生产配置固定回环地址及8080端口，启用`forward-headers-strategy: framework`解析Nginx转发头。Nginx应把`/api/`转发至本机后端，并正确设置Host、X-Forwarded-For、X-Forwarded-Proto；网站静态前端和TLS由主agent提供的部署资料管理，本文不改Nginx配置或服务器。

生产默认数据库URL指向`127.0.0.1:3306/study_room_reserve`，默认用户名`study_room`，密码使用必填环境变量`DB_PASSWORD`且没有明文默认值。`DB_URL`、`DB_USERNAME`可由受控运行环境覆盖。凭据必须只保存在部署环境受限权限的配置中，不放在源码、归档、命令输出或Git记录中。

Flyway开启且`clean-disabled=true`，只验证并应用未执行版本，V1/V2/V3未因生产打包修改；JPA保持`validate`，不会自行重建表。已有数据升级前由运维备份，应用不执行drop。生产`app.demo-seed=false`为固定配置，不读取`DEMO_SEED`环境变量，不能用该环境变量打开合成账号初始化。Spring外部配置仍可被管理员显式覆盖，部署管理者不得以额外参数或外置属性重新开启演示初始化。

## 日志、跨域及认证实现边界

根日志级别INFO；JPA `show-sql=false`，Hibernate SQL和绑定参数日志OFF（YAML使用带引号的字符串，避免被解析为布尔值）。生产不输出请求密码、令牌或数据库密码。不要追加全局DEBUG/TRACE或SQL绑定参数调试配置；错误处理保持统一响应并只记录内部异常类别。

`WebConfiguration`读取逗号分隔的`app.cors.allowed-origins`；默认开发仅允许localhost/127.0.0.1:5173，prod明确允许`https://www.zhangbowen666.cn`。同源网站通常不触发跨域，但配置也保留明确来源限制。允许GET/POST/PUT/DELETE/OPTIONS和Authorization、Content-Type，Bearer不依赖cookie。

项目只使用`spring-security-crypto`进行BCrypt密码哈希，**没有完整Spring Security认证FilterChain**。当前认证由MVC拦截器验证数据库Bearer会话，管理员与所有权权限由业务服务校验；不能把引入密码库描述为已经实现Spring Security过滤链。生产配置调整没有改动现有业务服务、30人容量或处罚规则。

## 可选本地演示构建

普通生产jar不能通过`--spring.profiles.active=demo`启动H2演示。需要演示时显式使用独立构建模式：

```bash
# 此包仅供合成演示，含H2与application-demo.yml；禁止用作生产归档。
mvn clean package -DskipTests -Pdemo
java -jar target/study-room-0.3.0.jar --spring.profiles.active=demo

# 演示结束后重新普通clean构建，最终交付必须是此模式的产物。
mvn clean package -DskipTests
```

测试不需要`-Pdemo`：普通测试classpath仍含H2与迁移后的测试配置；独立测试仍通过`@ActiveProfiles("test")`或其自身MySQL配置运行。本次只搬迁必要测试配置，未修改独立测试Java源。
